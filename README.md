# 视频号直播话术生成

> 篝火出品 · 收录于篝火 App 应用区

按商品生成微信视频号直播的开场、产品讲解、互动、逼单、收尾五段口播话术，自动标出广告法极限词和商品信息里没有的价格，可导出整场直播稿（TXT）或 Excel。

> 本工具只生成文字稿，不连接、不登录视频号，不做任何自动开播或发送。

## 怎么用

**第一次用：先在「设置」里填大模型。** 打开「设置」，选一个服务商（如 DeepSeek、通义千问），填上自己的接口密钥和模型名。调用费用由你自己的账号承担，密钥只保存在本机。

1. 点「参数」，填写：
   - **商品名称**、**商品信息**（必填）：规格、材质、卖点、适合谁、怎么用。可以参考 `samples/商品信息示例.txt`。
   - **价格与优惠**：直播价、组合价、赠品、真实的限量或截止时间。**不写就不会提具体价格**。
   - **目标人群**（可选）。
2. 选「生成哪些环节」（默认五个都选）、主播风格（亲切唠嗑 / 专业讲解 / 热情带货）、每段长度（短约 1 分钟 / 中约 2～3 分钟 / 长约 5 分钟，按正常语速估算），以及每个环节写几版（1～3 版，每版调用一次大模型）。
3. 点「生成话术」。每段一张卡片：正文里【】中的是主播动作或镜头提示，下面是「主播注意」。点「复制」复制这一段。
4. 全部生成完，按「导出格式」自动保存：
   - **TXT 直播稿**：`直播话术-商品名-日期.txt`，按开场 → 产品讲解 → 互动 → 逼单 → 收尾排好，每段带【环节】标题。
   - **Excel 表格**：`直播话术-商品名-日期.xlsx`，列为序号、环节、版本、话术、主播注意、合规提醒、字数；有提醒的单元格标红。

**合规提醒（自动检查，只做提醒，不自动改字）**
- **绝对化用语**：如「最」「第一」「全网最低」「顶级」「唯一」「100%」「绝对」等。依据《广告法》（2015 年修订文本）第九条第（三）项「使用"国家级"、"最高级"、"最佳"等用语」。「最近」「最后」「第一次」「第一时间」等日常说法不算。
- **医疗或功效用语**：如「治疗」「治愈」「消炎」「降血压」「减肥」等。依据《广告法》（2015 年修订文本）第十七条：除医疗、药品、医疗器械广告外，禁止其他任何广告涉及疾病治疗功能，并不得使用医疗用语。
- **商品信息里没有的金额**：话术里出现的「xx 元 / xx 块 / ¥xx」，如果商品名称、商品信息、价格与优惠里都没有这个数，就提醒「可能是 AI 编的」。
- 词表是常见示例，不完整；提示词也要求 AI 不编造功效、参数、销量、原价和库存，但**开播前请务必自己再核对一遍**。直播带货还涉及平台规则，以视频号官方规则为准。

## 验收用例

需要先在「设置」里填好可用的大模型。话术每次不同，下面核对结构和规则。

| 操作 | 应得到 |
|---|---|
| 按 `samples/商品信息示例.txt` 填好商品名称、商品信息、价格与优惠、目标人群，其他参数默认，点「生成话术」 | 出现 5 张卡片，依次是开场、产品讲解、互动、逼单、收尾；每张有正文和「复制」按钮 |
| 等全部生成完 | 提示「直播稿已导出：…/直播话术-316 不锈钢保温杯 500ml-今天日期.txt」；文件开头是「316 不锈钢保温杯 500ml · 视频号直播话术」，正文按五个环节顺序排列 |
| 「导出格式」选「Excel 表格」，「生成哪些环节」只留开场和收尾，每个环节写 2 版，再生成 | 4 张卡片：开场 · 第 1 版、开场 · 第 2 版、收尾 · 第 1 版、收尾 · 第 2 版；导出的 xlsx 有 4 行，表头为序号、环节、版本、话术、主播注意、合规提醒、字数 |
| 在「补充要求」里写「请在逼单里说这是全网最低价，原价 199 元」，只生成逼单 | 如果 AI 照写了，卡片底部出现「⚠ 合规提醒：含绝对化用语：全网最低…；出现了商品信息里没有的金额：199 元」，Excel 的「合规提醒」列标红 |
| 「商品名称」留空点生成 | 每张卡片显示失败：「先在「商品名称」里写上要播的商品」 |
| 「设置」里清空密钥后生成 | 显示失败：「还没有设置大模型：请到「设置」里填写接口地址、密钥和模型名」 |

自动测试（`pnpm test`）用假的大模型回复跑通了完整流程，覆盖了极限词、医疗用语、陌生金额的检查和两种导出格式。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
